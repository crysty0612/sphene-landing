Progressive Web App (PWA)

Get a true standalone, borderless app window on Windows, macOS, Linux, and Android with zero app store gatekeepers. Provides custom window titlebars, dock/taskbar icons, and offline asset caching.

How to Install:

  • Chrome / Edge (PC/Mac): Open your Sphene URL, click the Install Sphene icon in the URL bar.
  • Android: Open in Chrome/Brave → tap Menu (⋮) → Add to Home screen.
  • iOS / Safari: Tap Share icon → Add to Home Screen.
